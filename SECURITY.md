# Política de segurança

## Versões com suporte

| Versão | Suporte |
|---|---|
| 1.0.x | Sim |

## Como relatar uma vulnerabilidade

Não abra uma issue pública. Use **Security › Report a vulnerability** (GitHub Private Vulnerability Reporting) neste repositório e inclua:

- a versão do Pyhoma. e o banco de dados usado;
- os passos para reproduzir;
- o impacto que você identificou.

Responderemos assim que possível e combinaremos a divulgação depois da correção.

## Boas práticas para quem usa

- Use um usuário de banco exclusivo para o Pyhoma., com permissão apenas no banco dele.
- Prefira conexões criptografadas (TLS) com o servidor de banco.
- Mantenha o Windows e o Pyhoma. atualizados e faça backup do banco regularmente.
- Ao anexar logs em issues, remova nomes de servidores, usuários e endereços IP.
